## 📖 Overview

LearnHub is a learning management system (LMS) project exploring how students and course administrators can work within a single education platform. The project emphasizes **role-oriented screens**, clear information architecture, reusable React components, and responsive user interfaces.

The supplied project materials describe course management, student learning, assessments, progress reporting, and discussion features. This repository should be treated as a **portfolio/development project** unless its full application code and all workflows have been verified.

## ✨ Project Scope

### Administrator-oriented experience
- Course creation and course-management views
- Learning-material and content organization concepts
- Enrollment overview and administration dashboard layouts
- Dashboard cards and analytics-oriented presentation

### Student-oriented experience
- Course discovery and lesson-content interfaces
- Learning-progress indicators
- Quiz and assessment interface concepts
- Discussion/forum layouts for learner interaction
- Role-based navigation and responsive layouts

> **Implementation boundary:** These are the demonstrated or described project areas. The presence of a UI does not, by itself, establish secure production authentication, persistent enrollments, automated quiz evaluation, a working forum backend, or real-time analytics.

## ▶️ Local Development

If the repository includes the complete Vite application source:

```bash
git clone https://github.com/p-g-udara-dilshan/LearnHub-LMS-Platform.git
cd LearnHub-LMS-Platform
npm install
npm run dev
```

Open the local development address printed in your terminal. If defined in `package.json`, validate the build with:

```bash
npm run build
```

**Source availability note:** An earlier public repository snapshot contained configuration and documentation but did not expose the application `src/` directory. Check this repository's current files before assuming the above commands will run successfully. If application source or assets are missing, restore them before advertising a runnable demo.
